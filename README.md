# ⚡ Speed Dash

Um jogo 2D de plataforma inspirado nos clássicos jogos de velocidade, desenvolvido com **HTML5, CSS3 e JavaScript puro**, sem React.

O objetivo é atravessar a fase o mais rápido possível, coletando cristais, derrotando inimigos e desviando dos obstáculos pelo caminho.

## 🎮 Sobre o jogo

**Speed Dash** é um jogo de plataforma 2D focado em velocidade e exploração.

O jogador controla um personagem veloz que precisa chegar ao final da fase enquanto coleta cristais, enfrenta inimigos e supera diferentes obstáculos.

O projeto foi desenvolvido utilizando tecnologias web, permitindo que o jogo seja executado diretamente no navegador.

## ✨ Funcionalidades

* 🏃 Movimento rápido e fluido
* 🦘 Sistema de pulo
* ⚡ Sistema de impulso
* 💎 Cristais colecionáveis
* 👾 Inimigos com diferentes comportamentos
* ❤️ Sistema de vidas
* 🏁 Linha de chegada
* 🚩 Checkpoints
* 📷 Câmera acompanhando o personagem
* 🌄 Efeito de parallax no cenário
* 💨 Efeitos de velocidade e partículas
* 🔊 Efeitos sonoros com Web Audio API
* ⏱️ Cronômetro da fase
* 📱 Controles para dispositivos móveis
* ⏸️ Sistema de pausa
* 🎮 Tela de início, vitória e Game Over

## 🕹️ Controles

### Computador

| Tecla     | Ação                  |
| --------- | --------------------- |
| `A` / `←` | Mover para a esquerda |
| `D` / `→` | Mover para a direita  |
| `Espaço`  | Pular                 |
| `Shift`   | Impulso               |
| `P`       | Pausar                |

### 📱 Celular

O jogo possui controles virtuais na tela para movimentação, pulo e impulso.

## 🛠️ Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla JS)**
* **HTML5 Canvas**
* **Web Audio API**
* **RequestAnimationFrame**

> O projeto **não utiliza React**, frameworks ou backend.

## 🚀 Como executar

Não é necessário instalar dependências.

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/speed-dash.git
```

### 2. Entre na pasta

```bash
cd speed-dash
```

### 3. Execute

Abra o arquivo:

```text
index.html
```

diretamente no navegador.

Também é possível utilizar o **GitHub Pages** para publicar o jogo online.

## 🎯 Objetivo

O objetivo principal é chegar ao final da fase no menor tempo possível, tentando coletar o máximo de cristais e derrotar os inimigos encontrados pelo caminho.
